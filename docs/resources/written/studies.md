# ການສຶກສາຄຳພີໄບເບິນ

ການສຶກສາຄຳພີໄບເບິນທີ່ມີໂຄງສ້າງເປັນພາສາລາວ, ສຳລັບການສຶກສາສ່ວນຕົວ ຫຼື ກຸ່ມ.

ຊຸດການສຶກສາໃນປະຈຸບັນແມ່ນມີຢູ່ໃນ

ແອັບ **[LaoChristian.org](https://apps.laochristian.org/)** ພາຍໃຕ້ **ຊັບພະຍາກອນຄຣິສຕຽນ**, ບ່ອນທີ່
ສາມາດອ່ານແບບອອບໄລນ໌ ແລະ ປັບຂະໜາດຂໍ້ຄວາມໄດ້.
